What's inside

  • Frosted-glass desktop, Quick Settings, notifications and widgets
  • Snap layouts, movable desktop icons, any resolution your screen supports
  • Pluto Store, Browser, Paint, Terminal, games and more
  • Boots on UEFI; runs live from the disc or installs to a drive

Try it

  • Create a new virtual machine OR boot it on a real device (Use rufus to make it bootable)
  • If its a VM, give it 1GB+ RAM, 4GB Storage, 128/256MB VRAM, 3 cores, enable UEFI and attach it the ISO as the optical drive on the IDE controller.
  • Attach the ISO as the optical drive on the IDE controller and start the machine
  • WARNING: IF UEFI ISNT ENABLED THERE WILL BE NO DISPLAY.
  • Choose "Run without installing" or install to the virtual disk
